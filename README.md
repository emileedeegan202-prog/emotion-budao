# emotion-budao

独立网文 **情绪补刀** skill。与 **human-writing** 串联（完整改稿，非轻洗）；不融合 oh-story。

```text
草稿 → human-writing（fiction+revision+check_prose）→ emotion-budao
```

力度对齐此前改正文实操：① 认真改活人感与禁令；② 补微赢再撕 / 代价 / 反检查单。有 `设定/文风.md` 时番茄口吻优先。

## Install

```bash
npx skills add emileedeegan202-prog/emotion-budao -y -g
npx skills add KKKKhazix/human-writing -y -g
```

仓库：https://github.com/emileedeegan202-prog/emotion-budao

## Usage

```text
/emotion-budao 回炉第3章
/情绪补刀 第6章（跳过活人感）
```
