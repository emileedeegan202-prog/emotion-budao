# Prose gate

Portable hygiene rules for revised chapter text. No other skill install required.

## Hard bans (body text)

- No em-dash `——` / `—`
- No fullwidth colon `：` in narration (dialogue in 「」; UI blocks like `【】` OK if the project already uses them)
- No flip-rhetoric: 「不是A而是B」「你以为A其实B」「表面上A实际上B」「与其说A不如说B」 and variants
- No 3+ neat parallel lyric lines stacking abstractions
- No ending uplift into fate / era / “everyone”

## Sentence

- Subject + action first; conditions after  
- More than three 「的」 in one clause → split  
- Mix lengths; if action/dialogue already carries feeling, stop — do not add an explaining moral  
- Oral tone / `！` / light slang: **allowed** when the project voice wants heat

## Material

- Feeling rides on objects, body, quoted speech — not four restatements of a thesis  
- Every thickened emotion span must point to a concrete prop or sensation on the page  
- **Anti-checklist:** if the line restates a gate bullet (“won the scene but lost X”, “points < person”), rewrite into prop/glance (see emotion-gate §E)

## Pass check

Scan once: which line sounds like finishing a writing assignment → rewrite; which line is bigger than its material → cut; where the beat already ended → stop.
