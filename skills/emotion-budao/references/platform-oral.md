# Oral / platform cadence (portable)

Generic “short-form oral webnovel” mouthfeel — **not** tied to any title.  
Use when project `文风.md` is thin; if `文风.md` / Voice Brief exists, **Brief wins** on conflicts.

## Core rhythm

1. **Aside alone** — narrator roast / curse / one-beat judgment gets its **own paragraph**. Don’t bury it mid-narration.  
2. **Dialogue drives the peak** — punch scenes lean on back-and-forth, not essay.  
3. **Reaction layer** — after payoff, ≥1 concrete bystander beat; prefer **one deep** or **two unlike** reactions; ban three parallel slogan lines.  
4. **Misread comedy** — system / crowd / sidekick reads intent wrong at least once per chapter when the genre allows UI/crowd.  
5. **Short punches on release** — average sentence drops; one-line paragraphs OK at the snap.  
6. **Dense emotion ≤1–2 spans / chapter** — then immediately action or dialogue.

## Optional UI blocks

If the book has a system / panel:

- Keep mechanical lines inside project convention (e.g. `【】`)  
- Keep narrator roast **outside** the block for rhythm contrast  

## Punctuation defaults (override via 文风)

- Prefer period / comma breaks over em-dash sermons  
- `！` OK on comedy / expose peaks  
- Fullwidth `：` in narration: avoid (prose-gate)

## Chapter title energy (optional)

Oral titles often sound like a line someone would screenshot — question, price, rule flip, self-burn — not thesis slogans.
