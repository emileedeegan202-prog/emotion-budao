# Emotion gate

Self-contained. No external book corpus required.

## A. Six beats (minimum)

Mark each; missing any of build / wound / cost / warmth = fail.

| Beat | Question | Portable landings |
|------|----------|-------------------|
| **Build** | What does the lead want to hold today? | Paper, empty reward, unpaid favor, unfinished message |
| **Wound** | What hits a private nerve? | Family, debt, shame, being misread, “still no progress” |
| **Release** | Where does the reader get payoff? | Rule flip, expose, clean counter, crowd turn |
| **Cost** | What is still lost after winning the moment? | Help incomplete; applause vs still-light paper; new debt; wrong label |
| **Warmth** | Who/what keeps the reader caring? | One soft look, one owed kindness, old ritual object |
| **Comedy** | One small misread / contrast? | Crowd wrong, helper wrong, narrator roasting self |
| **Hook** | What unfinished consequence remains? | Unanswered message, watching car, missing points, open case |

Only **release + comedy** → chapter feels oily and empty.

## B. Soft-win then tear (opening / build amplitude)

Do **not** open on pure misery. Give a beat where the lead still looks competent / in control, then empty the result.

Portable moves (pick what fits the cast — not luxury-by-default):

| Soft-win (reader almost envies / trusts) | Tear |
|------------------------------------------|------|
| Knows the ritual better than bystanders | Stamp returns the same old paper |
| Clothes/shoes still orderly | Reward slot still empty |
| Clerk recognizes the routine (“same file”) | Content unchanged |
| Can finish the form/flow | Outcome still zero news |

**Fail:** only “I’m tired / unlucky” with no contrast.  
**Pass:** someone else fumbles beside them → they look sharp → result still hollow.

Genre note: peak can be social luxury **or** procedural competence. Match the protagonist’s world.

## C. Three knives (wound / opening spans)

1. **Body first** — fatigue, empty stomach, exhaled breath, cold underfoot — body before naming the feeling.  
2. **Self-contradiction** — the comforting line (“I’m luckier than most”) that still fails — the comfort is the ache.  
3. **Atmosphere before kinship** — song / smell / worn object opens distance (**let the cue linger one extra beat**), then the missing person surfaces; do not jump-cut to crying keywords.

## D. Whole-book patches

4. **Cost** — most common missing beat after payoff. Prefer **object contrast** (applause in ear / paper still light in pocket) over slogan summary.  
5. **Object empathy** — cracked clip / taped pen / soft banknote edge **before** the lead acts.  
6. **Multi-reaction** — ≥2 different bystander reads (laugh / freeze / dare-not-laugh). No three-line parallel slogan stack.  
7. **People over meters** — when a score/UI celebrates, show the human still standing / refusing; don’t thesis-state “points < people”.

## E. Anti-checklist voice (hard)

These read as “finishing a writing assignment”. Rewrite into prop / body / glance:

| Checklist smell | Prefer |
|-----------------|--------|
| “Won the room, lost X” | Applause vs still-light object |
| “Not sympathy — recognition” | One shared gesture/habit echo |
| “Points matter less than them sitting” | Look up; they are still standing |
| “No wine here, only N years” | Dry empty stomach / throat block |
| Stacked abstract nouns (命运/人生) | Cut |

If a line could be a bullet on this gate file, it does not belong in the chapter.

## F. Micro-cycle

```
Setup → Action → Release → Cost → New hook
```

Skipping **cost** is the usual reason emotion floats.

## G. Portable engines

| Engine | Move |
|--------|------|
| Soft-win then tear | Competence/ritual win → empty result |
| Theme misread | Intent A read as villainy / comedy by others |
| Object empathy | Care via props, then act |
| Multi-reaction | Same frame, split crowd |
| Emotional deposit | Old object/ritual returns when hate rises |
| People-first | Warmth chapter may score zero and still matter |

## H. Forbidden

- Emotion **tags** without body pause  
- Soft-win missing on opening ache chapters  
- Instant joke UI right after payoff, zero cost  
- Checklist slogans (section E)  
- Abstract sermons about fate / life / era  
- Changing plot anchors just to “feel more”
