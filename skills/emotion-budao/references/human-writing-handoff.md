# human-writing 对接（按改正文实操，不是轻洗）

本技能**不内嵌** [human-writing](https://github.com/KKKKhazix/human-writing) 全文，但改章时 **① 按完整改稿手法跑**，力度对齐此前把章节从空心稿改到可发水平的做法——**不是**只扫一遍破折号。

```text
已有正文草稿
  → ① human-writing（完整改稿：fiction + revision + check_prose）
  → ② emotion-budao（情绪结构：微赢再撕 / 代价 / 反检查单 / 口语反应）
```

story / oh-story **不在本链融合**。

## ① 怎么跑（对齐既往改正文）

若已安装 `human-writing` 且用户未要求跳过：

1. 读 `references/fiction.md`（虚构：人物眼下要办的事、对白做事、场末变化、设定晚揭）  
2. 初稿已存在 → 读 `references/revision.md`，按七遍改稿走完：  
   - 谁在说 / 段落是否往前走 / 拆表演性中文 / 中文顺口 / **硬禁用项** / 设定自洽 / 结尾不空喊  
3. 跑 `scripts/check_prose.py`（若存在），硬禁令清零再交 ②  
4. 该加厚的反应、该删的注水、该改的叙述位置——**按 revision 正常改**，不要自我阉割成「只改三处标点」

用户说「跳过活人感 / 只用情绪补刀」→ 跳过 ①。  
未安装 → 跳过 ①；② 的 `prose-gate` 仍做硬禁令兜底（力度弱于完整 human-writing）。

## 与项目文风的冲突规则（重要）

既往改稿结论：**文风/番茄口吻优先于 human-writing 的「长帖散文默认」**。

| 听谁的 | 例子 |
|--------|------|
| **`设定/文风.md` 优先** | 短句连斩、吐槽单独成段、感叹号、系统误读喜点、反应层加长 |
| **human-writing 照做** | 叙述位置、场末要有变化、拆假深刻/假具体、禁 `——`/`：`/翻案句、删同义注水 |
| **禁止** | 为「更像知乎长文」削掉围观起哄、把口语洗成书面完整句、用说教尾巴收章 |

① 改完若变「干净但平」，② 必须按 emotion-gate / platform-oral **补回情绪与口语密度**，不要把平稿当终局。

## ② 与本包分工

| 层 | 谁管 |
|----|------|
| 活人叙述、场戏推进、表演腔、硬禁令、check_prose | **human-writing（①）** |
| 六拍、微赢再撕、代价物件、反检查单、番茄口语反应层 | **emotion-budao（②）** |

① 可以动结构句段；② 在①之后专门补「疼/代价/温度」，并再跑本包 prose-gate + 字数。

## 不要

- 把①收成「轻洗」敷衍  
- ①之后再跑一轮**重度** human-writing 冲掉②的情绪补丁（禁令复扫可以，整章重写不要）  
- 未读 fiction/revision 就宣称「已按 human-writing 改过」
